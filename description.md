# NutriAI Premium Features - Документація

## Огляд

Цей документ описує всі Premium функції для вебсайту NutriAI. Кожна функція задумана для кабінету користувача (dashboard) або окремої сторінки.

**Ціна:** $9.99/місяц  
**Вільний період:** 7 днів  
**Платформа:** Вебсайт (не мобільний)

---

## 📊 1. Детальна аналітика і звіти

### Описа

Користувач бачить свої дані не тільки за день, а й за місяц, рік. Видны тренди, відхилення, порівняння з нормами.

### Що входить

#### 1.1 Графіки за місяц/рік

```
Графік 1: Калорійність за 30 днів
  ├ X-вісь: дати
  ├ Y-вісь: калорії (0-3000)
  ├ Лінія: середня калорійність
  ├ Пунктирна лінія: ціль
  └ Приховування вихідних (опція)

Графік 2: Макроси за місяц (складений)
  ├ Білки (%)
  ├ Жири (%)
  ├ Вуглеводи (%)
  └ Послідовність днів
```

#### 1.2 Порівняння з нормами USDA

```
Таблиця для кожного юзера:
  ├ Натрій: 2100mg (норма 2300) → ✅ OK
  ├ Білки: 85g (норма 50) → ⚠️ На 70% більше
  ├ Калорії: 1800 (норма 2000) → ✅ OK
  ├ Жири: 60g (норма 70) → ✅ OK
  └ Цукор: 45g (норма 25) → ❌ На 80% більше

Рекомендація ШІ:
  "Твій цукор завик. Спробуй замінити сніданок на низькосахаристий"
```

#### 1.3 Макрос тренди

```
Порівняння періодів:
  Цей місяц vs Попередній:
    ├ Білки: 85g → 92g (+8%)
    ├ Жири: 60g → 58g (-3%)
    ├ Вуглеводи: 200g → 215g (+7%)
    └ Висновок: Більше білків - добре, дотримуватись

Порівняння: Вихідні vs Будні:
    ├ Будні: 1750 cal середнього
    ├ Вихідні: 2150 cal середнього
    └ Висновок: Вихідні на 400 cal більше
```

#### 1.4 PDF звіт на місяць

```
Структура звіту:
  ├ Титульна сторінка
  │   ├ Ім'я користувача
  │   ├ Період (15.08 - 14.09.2026)
  │   └ Дата генерації
  │
  ├ Зведення
  │   ├ Середня калорійність
  │   ├ Досягнення цілей (%)
  │   ├ Дні з дефіцитом
  │   └ Вага зміна (до/після)
  │
  ├ Графіки
  │   ├ Калорії за період
  │   └ Макроси складені
  │
  ├ Таблиця днів
  │   └ Кожен день: калорії, макроси, досягнення
  │
  └ Рекомендації
      └ На основі ШІ аналізу
```

#### 1.5 Calendar тепла-карта (як GitHub)

```
Макет:
  ┌─ П В С Ч П С Н ─┐
  │ ░░░░░░░░░░░░░░  │
  │ ░░░░███░░░░░░░░ │
  │ ░░███████░░░░░░ │
  │ ░███████░░░░░░░ │
  │ ░░░░██░░░░░░░░░ │
  └────────────────┘

Кольори:
  ░ Білий: День з дефіцитом калорій (OK)
  ▓ Сірий: День в нормі (OK)
  █ Зелений: День з превисуком (досяг цілі)
  ░ Пустой: Немає даних

Посцільма: На дату → деталі дня
```

### Технічні вимоги

**Backend:**
- Запит до БД: aggregation по dates
- Розрахунок USDA норм на основі віку/статі/активності
- ШІ (ChatGPT) для рекомендацій (1 запит = $0.01)

**Frontend:**
- Chart.js або D3 для графіків
- HTML Canvas для тепла-карти
- PDF генератор (jsPDF/pdfkit)

**Вартість ШІ:** ~$0.50/користувач на місяц

## 🍽️ 2. Меню-планер на місяць

### Описа

ШІ генерує персоніковане меню на місяць на основі цілей користувача. Може редагувати рецепти, експортувати список покупок.

### Що входить

#### 2.1 Календар на місяць

```
Макет:
  Вибір цілі (у модалі):
    ├ Калорії: [1500] cal
    ├ Білки: [30]%
    ├ Жири: [40]%
    ├ Вуглеводи: [30]%
    └ [Generate Menu] (червона кнопка)

Після генерації:
  ┌─ Понеділок ─┬─ Вівторок ─┬─ Середа ─┐
  │ Сніданок    │ Сніданок   │ ...      │
  │ Яйця (280)  │ Каша (300) │          │
  │             │            │          │
  │ Обід        │ Обід       │          │
  │ Курка (450) │ Риба (400) │          │
  │             │            │          │
  │ Вечеря      │ Вечеря     │          │
  │ Салат (180) │ Суп (250)  │          │
  │             │            │          │
  │ ВСЬОГО: 910 │ ВСЬОГО:950 │          │
  └─────────────┴────────────┴──────────┘
```

#### 2.2 Edit Recipes

```
Клік на день → модал:
  ├ Понеділок
  │   ├ Сніданок: Яйця + хліб
  │   │   ├ [Edit recipe]
  │   │   │   ├ Замінити яйця на яйця у сніданок
  │   │   │   ├ Замініт хліб на батату
  │   │   │   └ [Save]
  │   │   │
  │   │   └ [Delete this meal]
  │   │
  │   ├ [Add meal]
  │   │   ├ Введи назву
  │   │   ├ Введи калорії
  │   │   └ [Save]
  │   │
  │   └ ВСЬОГО: 910 cal
  │
  └ [Save changes]
```

#### 2.3 Export as PDF

```
[Export Menu] → PDF файл завантажується

Формат:
  ├ Календар рецептів (30 днів)
  ├ Всі інгредієнти
  ├ Калорії на кожну страву
  ├ Помічки для готування
  └ Список покупок на першу неділю
```

#### 2.4 Import to Shopping List

```
[Generate Shopping List]
  
Після натиску:
  ├ Система збирає ВСІ інгредієнти з 30 днів
  ├ Групує по категоріям (овочі, м'ясо, молочне)
  ├ Показує кількість (10x яйця, 2kg курки)
  ├ Можна редагувати (добавити що забув)
  ├ [Export as PDF] - роздрукуй або відправ сім'ї
  └ [Share with family] - посилання на список
```

### Технічні вимоги

**Backend:**
- ШІ (ChatGPT API): "Generate menu for 30 days with 1500 cal, 30% protein, 40% fat, 30% carbs"
- Калькулятор калорій для кожної страви
- Парсинг рецептів (веб-скрейпінг або база)

**Frontend:**
- Modal для редагування
- Drag-drop для переорганізації днів
- PDF експортер

**Вартість ШІ:** ~$1-2 за один запит (1 меню = 1 запит)  
**Кількість запитів на користувача в місяц:** ~2-3 = $2-6

- Real-time оновлення позиції

**При 50 challenges/місяц = $150**

## 📝 4. Лічба макросів з історією

### Описа

Детальна історія введення їжи з аналізом помилок, рекомендаціями, і можливістю дублювати дні.

### Що входить

#### 4.1 История за 90 днів

```
┌─ Дата ─┬─ Калорії ─┬─ Білки ─┬─ Жири ─┬─ Вуглі ─┬─ Дія ─┐
│ 14.09  │ 1850      │ 92g     │ 62g    │ 210g   │ [+]  │
│ 13.09  │ 1920      │ 95g     │ 65g    │ 215g   │ [+]  │
│ 12.09  │ 2100      │ 85g     │ 70g    │ 240g   │ [+]  │
│ 11.09  │ 1750      │ 88g     │ 58g    │ 200g   │ [+]  │
│ 10.09  │ 1680      │ 90g     │ 55g    │ 195g   │ [+]  │
│ ...    │ ...       │ ...     │ ...    │ ...    │ ... │
│ 15.06  │ 3200      │ 110g    │ 120g   │ 350g   │ [+]  │
└────────┴───────────┴─────────┴────────┴────────┴─────┘

Клік на дату → Розгорнути:
  ├ Понеділок 14.09
  │ ├ Сніданок
  │ │   ├ Яйця вареные (2x) - 155 cal
  │ │   ├ Хліб чорний (1 скибло) - 80 cal
  │ │   └ Масло вершкове (1 ч.л.) - 100 cal
  │ │   Сніданок ВСЬОГО: 335 cal
  │ │
  │ ├ Обід
  │ │   ├ Курка гриль 200g - 330 cal
  │ │   ├ Рис вареній 150g - 195 cal
  │ │   └ Овощі - 50 cal
  │ │   Обід ВСЬОГО: 575 cal
  │ │
  │ ├ Вечеря
  │ │   ├ Риба 150g - 240 cal
  │ │   └ Салат - 50 cal
  │ │   Вечеря ВСЬОГО: 290 cal
  │ │
  │ ├ Закуски
  │ │   └ Яблуко - 50 cal
  │ │
  │ └ ВСЬОГО: 1850 cal | P: 92g | F: 62g | C: 210g
  │   [Edit day] [Duplicate this day] [Delete]
  │
  └ Повернутись до списку
```

#### 4.2 Найпопулярніші страви

```
[Analytics] → [Top Foods]

┌─ Страва ────────────────┬─ Разів ─┬─ Останнє ─┬─ Дія ─┐
│ Курка гриль 200g       │ 45x    │ 13.09    │ [+]  │
│ Рис варений 150g       │ 38x    │ 12.09    │ [+]  │
│ Яйця вареные 2x        │ 35x    │ 14.09    │ [+]  │
│ Яблуко 1шт             │ 32x    │ 14.09    │ [+]  │
│ Салат з помідорами     │ 28x    │ 11.09    │ [+]  │
│ Каша вівсяна на молоці │ 22x    │ 10.09    │ [+]  │
│ ...                    │ ...    │ ...      │ ... │
└────────────────────────┴────────┴──────────┴─────┘

Приклад юзовання:
  Клік [+] на "Курка гриль 200g"
  → Автоматично додає до сьогодняшнього дня
```

#### 4.3 Найбільші помилки (ШІ аналіз)

```
[Insights] → [Mistakes]

ШІ дає рекомендації на основі даних:

1. "Твій сніданок завик перевищує цілі на 20%"
   └ Рекомендація: Спробуй нижчокалорійний сніданок
      Приклад: Каша з молоком (250 cal) замість яєць+масла (300 cal)

2. "Вечеря твоя в 21:00 - надмірна (400+ cal)"
   └ Рекомендація: Перемісти обід + вечеру на раніше
      Ефект: Краще спання, менше ночних перекусів

3. "Вихідні твої мають +400 cal дефіцит від будніх"
   └ Рекомендація: Спробуй знизити вихідну мету на 10%
      Вихідні - день відпочинку, це нормально

4. "80% днів ти не досягаєш білкової цілі"
   └ Рекомендація: Додай 1 яйце або 50g куриці до обіду
```

#### 4.4 Bulk Add - копіювання дня

```
[Quick Actions] → [Copy Day]

Форма:
  ├ Select source day: [Понеділок 08.09 ▼]
  ├ Select target day: [Сьогодні 15.09 ▼]
  ├ Scale calories: [100%]
  │  └ Якщо хочу той же день, но 20% більше = [120%]
  │
  └ [Copy Day] → Додає всю їжу одного дня в інший

Результат:
  14.09 (з минулого тижня):
    ├ Сніданок: 335 cal
    ├ Обід: 575 cal
    ├ Вечеря: 290 cal
    └ ВСЬОГО: 1200 cal

  15.09 (сьогодні):
    ├ [Скопійовано]
    ├ Сніданок: 335 cal
    ├ Обід: 575 cal
    ├ Вечеря: 290 cal
    └ ВСЬОГО: 1200 cal (можна редагувати)
```

#### 4.5 Очищення від помилок

```
[Data Management] → [Remove Duplicates]

Форма:
  ├ Дата inicio: [15.08 ▼]
  ├ Дата fin: [15.09 ▼]
  │
  └ [Find duplicates] → Показує:
     Знайдено 3 дублікати (однакові записи одного дня):
       ├ 08.09: "Курка 200g" x2 (додана 2 рази)
       ├ 10.09: "Яйця" x3
       └ 12.09: "Салат" x2

  [Remove all] → Вилучає дублікати

  Або ручне видалення:
    ☑ 08.09: "Курка 200g" (другий запис) [Delete]
```

### Технічні вимоги

**Backend:**
- Витягування всіх meals за період (90 днів)
- Агрегація по типу їжи (найчастіші)
- ШІ (ChatGPT): аналіз помилок (3-5 запитів на користувача на місяц)
- Дублікат детекція (простий regex)

**Frontend:**
- Таблиця з сортуванням
- Модальні для деталей
- Bulk операції (select multiple)

**Вартість ШІ:** ~$0.50/користувач на місяц

## 📈 6. Калькулятор дефіциту (Deficit Calculator)

### Описа

Прогнозує скільки днів потрібно, щоб досягти цілі з поточним дефіцитом. Показує коригування мети при зміні ваги.

```
│ Time passed: 90 днів                 │
│ Avg deficit: -445 cal/day             │
│ Total lost: 4 kg                      │
│ Rate: -0.044 kg/day (-0.31 kg/week)  │
│                                      │
│ [Edit goal weight]                   │
│ Goal weight: [70] kg                 │
│                                      │
│ Based on your deficit:                │
│   └達到 70kg будет за ~22-25 днів  │
│   └ Примеру дата: ~10.10.2026         │
└──────────────────────────────────────┘
```

#### 6.2 Прогноз ваги (Time-to-goal)

```
Графік прогнозу:

  75 kg │
        │ ╱─────╮  Current trajectory
  73 kg │ │
        │ │
  71 kg │─╯─────● You are here (14.09)
        │
  70 kg │       │ Projected (10.10)
        │       │
  69 kg │       └──● Goal
        │
        └────────────────────────
          15.06  14.09  10.10   01.11

Інтерпретація:

   то досягну 70kg за 22-25 днів (10.10)"

Альтернативні сценарії:
  ├ Якщо -500 cal/день → 19-20 днів
  ├ Якщо -400 cal/день → 25-28 днів
  └ Якщо -300 cal/день → 33-35 днів
```

#### 6.3 Регулювання цілі автоматично

```
Через 7 днів система автоматично перестраховує:

  ├ Дата: 10.10

Стало (юзер похудів на 1kg більше):
  ├ Ціль: 70 kg (та ж)
  ├ Нова дата: 05.10 (на 5 днів раніше)
  ├ Новий дефіцит: -470 cal/день (більш інтенсивно)
  └ Повідомлення: "🎉 Ти йдеш швидше, ніж очікували!"

Юзер бачить:
  [Auto-adjusted goals]
  ├ Старий прогноз: 10.10
  ├ Новий прогноз: 05.10
  ├ Різниця: -5 днів
  ├ [Keep new goal] (обрано за дефолтом)
  └ [Revert to old goal]
```

#### 6.4 Карма-мотиватор

```
Система показує мотивуючі повідомлення:

[Dashboard notifications]
  ├ 🎯 Ще 3 дні до половини цілі!
  ├ 📈 Цей тиждень на 8% краще, ніж попередній
  ├ 🔥 47 днів без пропусків - крутецко!

  ├ ⚡ Прискорення: твоя вага падає швидше
  └ 🏆 Ще 500 cal - досягнеш піку тижня!
```

### Технічні вимоги

**Backend:**
- Отримання ваги історії юзера
- Розрахунок лінійної регресії дефіциту
- Прогнозування дати досягнення цілі
- Перевірка кожен день (автоматичне коригування)

**Frontend:**
- Chart.js для прогнозу (лінія фактичного + передбачена)
- Введення цілі
- Показ альтернативних сценаріїв

**Вартість:** Безкоштовна (рахунки локально, без ШІ)
